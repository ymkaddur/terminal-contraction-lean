# Independent statement contracts

The classification contract is pairwise agreement on the joint side and message fibers. A decoder is constructed by choosing a representative of each occupied fiber. The empty fibers require only an inhabited answer type. With split residual coordinates, the finite alphabet minimum is exactly the field size raised to the product of the two residual dimensions. The zero-dimensional cases give one label.

Build with the pinned Lean toolchain and run python scripts/audit_module.py FiberMessagePins.
